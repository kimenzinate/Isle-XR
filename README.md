# Isle-XR

### Your island, always with you.

Isle is a connected mobile and XR experience designed to support international students experiencing homesickness. Rather than providing generic wellbeing content, Isle transforms the user’s own photos, videos, voice recordings and familiar objects into a personal floating island.

The mobile experience allows users to check in, choose their desired ambience and add meaningful memories. In the Apple Vision Pro experience, these memories become spatial cues that users can explore by looking at an item and pinching to select it. Users can open familiar content, discover a random memory through **Surprise Me**, reflect on how they feel and receive a gentle suggestion for returning to everyday life.

This repository contains the XR prototype developed for visionOS using SwiftUI and RealityKit.

Isle was created as a Major Project for the MA User Experience Design course at the University for the Creative Arts.


####How to Run the XR Prototype####

A Mac with Xcode and the visionOS Simulator installed is required.

Open the GitHub repository.
Click Code, then select Download ZIP.
Extract the downloaded ZIP file.
Open Isle.xcodeproj in Xcode.
Select Apple Vision Pro as the run destination.
Click Run (▶). Xcode will build the project and open the visionOS Simulator.
Using the Simulator

Gaze(Look): Move the mouse or trackpad pointer.
Pinch(Select): Point at an item and click.
Pinch and Move (Drag): Click and hold while moving the pointer.
Move around: Use the navigation controls in the bottom-right corner of the Simulator.
